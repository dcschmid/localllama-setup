# Documentation

All repository docs are English; the installed user-facing docs under
`~/.config/llama.cpp/` are byte-managed from `docs/` (drift refreshes with a
backup in `~/.local/state/localllma-setup/doc-backup/`). The pages below
cover the current architecture and workflows; SETUP.md, RESTORE_TEST.md,
MODEL_BENCHMARKS.md, and PERFORMANCE_OPTIMIZATION.md additionally carry the
November 2026 measurement and operations record with every value preserved.
