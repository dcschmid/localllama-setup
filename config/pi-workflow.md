# Local coding workflow

Confirm the task and acceptance criteria. Load the applicable shared skills
before choosing tools. Start with a targeted search, use symbols when they
narrow the scope, then read the smallest relevant excerpt. Read whole files
when a change depends on their wider structure.

Plan only as much as the change requires. Make small, precise edits in the
existing style. Run the focused tests or build after the change and use the
first actionable failure to guide the next edit. When the same failure
recurs, inspect its cause and change tactics before retrying.

Review the diff and run the relevant acceptance checks before finishing.
Keep decisions, completed work, open tasks, affected paths and test results
available when resuming or compacting. Report the outcome and remaining
checks briefly.
